## 现有 FR-04 原型

一个可在本机运行的课程原型：上传或粘贴一个 Python 纯函数，选择文件注释或手写功能说明，调用 DeepSeek 生成结构化测试，核对并确认后实际执行，保存报告。

## 启动

需要 Python 3.10 或更高版本，无第三方 Python 包、Node 安装或数据库安装步骤。

1. 配置 `DEEPSEEK_API_KEY`：可使用现有 Windows 用户环境变量，也可填写项目目录的 `.env`。文件已被 `.gitignore` 排除。
2. 双击 `start.cmd`，或在项目目录运行：

   ```powershell
   python app.py
   ```

3. 浏览器打开 <http://127.0.0.1:8765>。停止服务时在终端按 `Ctrl+C`。

配置每次生成时重新读取，修改后无需重启后端，页面点击“刷新配置”即可。读取优先级为当前进程环境变量、`.env` 非空值、Windows 用户环境变量、默认值。因此启动应用后才设置的 Windows 用户变量也能被读取，密钥不会显示在页面或日志中。端口占用时可运行 `python app.py --port 8766`。

配置示例（不要提交真实密钥）：

```dotenv
DEEPSEEK_API_KEY=你的密钥
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-flash
```

若你使用的账户或兼容服务提供其他模型，修改模型名和 API 地址。默认模型以 DeepSeek 官方当前文档为依据；服务不会自动切换模型或伪造成功响应。

## 上传自己的 Python 文件

1. 点击“上传 Python 文件”，选择一个 `.py` 文件。系统自动识别其中唯一的独立函数，展示完整代码；也可以直接粘贴代码。
2. 选择说明来源：**文件注释**会提取模块/函数 docstring 和 `#` 注释供预览；**手写功能说明**使用你在文本框中填写的内容。两种来源不混合。
3. 说明需要写清输入范围、返回值与异常。普通中文说明可直接使用，系统会自动添加 `R1：` 以关联用例；已有 R 编号会保留。没有注释时可改用手写说明。
4. 点击 **DeepSeek 生成用例**，核对实际使用的说明和各例预期，勾选确认后点击 **确认并运行**，查看真实结果并下载报告。

可先上传 `examples/shipping_fee_comments.py`：注释要求 `>=99` 免邮，实现使用 `>99`，测试应发现 99 元的边界错误。改用手写说明并要求 `>99` 时，应生成另一版本的预期。另有 `examples/absolute_value.py` 可体验 `#` 注释提取。

上传支持 UTF-8/BOM 以及带 Python 编码声明的文件，最多 80 KB；解码后统一为 UTF-8 文本，非 UTF-8 编码声明也会统一。上传和提取时只做静态解析，不执行文件。一次仍只支持一个无外部依赖的独立函数。

## 三分钟演示

1. 选择 **S1 · ≥99 免邮**，点击 **DeepSeek 生成用例**。
2. 检查用例中的 0、98、99、100、1000、-1、1001；特别确认 `99` 的预期是 `0`。
3. 勾选核对确认，再点击 **确认并运行**。样例实现故意用了 `>99`，所以 `99` 应产生断言失败，其他六个必需输入通过。
4. 切换 **S2 · >99 免邮**，重新生成、核对和运行。`99` 的预期应变为 `10`，样例应全部通过。
5. 查看历史任务，确认 S1 原报告保留。可以下载测试文件和完整 JSON 报告。

尚未配置 API 时可点击 **演示流程（不调用 AI）**。演示使用显式固定数据，执行结果仍然是真实子进程产生，但不能当作模型效果验收证据。

勾选 **模拟生成超时** 后点击生成，可检查约 60 秒结束等待、失败留痕及不执行被测代码。关闭故障开关后重试将创建新任务。

## 支持范围

- 一个同步、独立函数；最多 200 个物理行，代码最多 20000 字符；说明最多 2000 字符。
- 无 import、类、装饰器、外部依赖、顶层可执行语句、嵌套函数、默认参数或可变参数。
- 支持简单 JSON 输入与预期，常见算术、分支、循环、列表/字典操作及白名单内的纯内置函数和方法。
- 功能说明可手写或从注释提取，普通文本自动添加 `R1：`；对未定义行为返回“待补充说明”。2000 字符限制包括自动添加的编号。
- 最多 10 条用例；页面默认 7 条，可选择 1～10 条。异常类型按名称精确匹配。
- 每次真实生成最多两次模型调用：初次生成和一次结构修正，总时间预算 60 秒。
- 每次运行总时间预算 10 秒，逐例使用新进程。生成/校验阶段不导入和执行提交代码。

执行方式为 **本地教学受限执行，不是生产安全沙箱**：AST 白名单、最小内置函数集合、子进程、清理环境变量、超时终止；Windows 上尝试施加 256 MiB Job Object 内存限制，并在报告中记录是否成功。不要把本原型暴露为公共代码执行服务。完整 Docker/VM 隔离属于后续工作。

## 数据与真实性

每个任务保存到 `data/tasks/<task-id>/`：

- `subject.py`：本次确认使用的代码快照（UTF-8）。
- `spec.txt`：本次真正送入模型的说明，包含规则编号。
- `test_generated.py`：从已校验用例生成的标准库 unittest 文件。
- `task.json`：文件名、说明来源、原手写说明、提取的注释及行号、实际说明、版本哈希、模型/提示词版本、调用与修正记录、原始模型响应、人工确认、逐例实际结果和源码前后哈希。

原型在受限进程中按确认后的同一组数据执行固定断言；下载文件是同组用例的独立 unittest 表达。下载后将原代码另存为同目录的 `subject.py`，运行 `python -m unittest test_generated.py -v`。独立运行下载文件不包含网页执行器的限制，仅适用于自有代码。

任务不会因为测试失败而修改预期。生成失败没有通过结论。模型失败不会回退为演示数据。修改输入需重新生成和确认；重试新建任务并保留旧失败记录。

## 检查与验收

运行不需要真实 API 的开发测试：

```powershell
python -m unittest discover -s tests -v
```

测试包括：S1/S2 的实际执行差异、预期异常、超时终止、AST 支持边界、参数匹配、最多一次修正、响应体卡住时的总期限、确认前不执行、版本变化、失败记录保留及本机接口防跨站请求。

运行中的网页服务可配合验收脚本：

```powershell
# 固定演示数据，仅验收工作流
python scripts/acceptance.py --mode demo --rounds 1 --confirm-fixtures

# 真实模型：T1/T2 各三次，明确同意执行脚本内的固定课程样例
python scripts/acceptance.py --mode real --rounds 3 --confirm-fixtures

# 可加 --fault 检查一次 60 秒故障及恢复，完整保留 8 次记录
python scripts/acceptance.py --mode real --rounds 3 --confirm-fixtures --fault

# 上传文件，两种说明来源的真实生成与执行
python scripts/upload_acceptance.py --confirm-fixtures
```

脚本会先独立核对生成预期；不正确的结果计为验收失败，不会修改用例再运行。结果汇总保存在 `data/acceptance/`，原始任务仍在任务目录。演示模式不计为真实 AI 验收。

## 常见问题

- **页面显示未配置**：确认 Windows 用户变量名称为 `DEEPSEEK_API_KEY`，或填写 `.env`（不是 `.env.example`），然后点击刷新配置。
- **HTTP 401**：检查密钥及所用 API 地址；页面与日志不需要显示密钥。
- **HTTP 402**：检查 DeepSeek 账户余额。
- **HTTP 400 / 模型不存在**：核对账户可用模型名与兼容接口配置。
- **生成超时**：保留失败任务，确认网络与服务状态后重试；两次模型调用共享 60 秒，不会无限重试。
- **源码不受支持**：按页面提示将样例缩为一个不带依赖的纯函数。
- **端口占用**：使用 `--port 8766` 启动并访问相应地址。
